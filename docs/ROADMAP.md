# ArchForm 开发计划

> 这个文件是项目计划的唯一记录。每次开发前先看这里:做到哪一步了、下一步要做什么。做完一项,就把状态改掉。

## 这个工具是做什么的

一句话:**把画框图变成填表单。**

编辑左侧结构树(图 → 层 → 分组 → 模块 → 条目),画布自动排版;样式、配色统一;完全离线,双击就能用。

## 为什么做这个(背景)

国内架构师画分层架构图(总体架构、应用架构、数据架构、技术架构等)时,用 draw.io、Visio 这类画布工具很痛苦:

1. **分层图其实是"嵌套结构",不是自由画布**——画布工具要手工拉框、对齐、调间距,时间花在"摆"而不是"想"
2. **风格靠人自觉**——字号、颜色、命名不统一,评审时吵的是风格,不是架构
3. **改版是灾难**——方案改几轮,画布要重新排版;结构化数据改一个词,自动重排
4. **没法版本管理**——图存在 Visio/draw.io 文件里,不能像代码一样 diff、review、追溯
5. **内容锁死在文件里**——架构资产没法复用
6. **没有中文场景模板**——总体架构、数据中台、数仓分层这些高频场景,现成模板是空的

结论:分层架构图应该"填数据 → 自动排版 → 统一规范"。这就是本工具做的事。

- **树操作 JS 拆分**:新增 `editor-tree.js`(树渲染/节点操作/快速录入/复制粘贴/右键菜单),editor-ui.js 精简

- **树内快速录入**:结构树底部输入框,Enter 确认 / Tab 下钻 / Shift+Tab 上升 / Esc 退出,当前层级与快捷键提示

- **树节点复制/粘贴**:深拷贝结构(层/分组/模块,含所有子级),智能插入(同层=兄弟,容器=子级),Ctrl+C / Ctrl+V
- **树右键菜单**:新建/复制/粘贴/上移/下移/删除
- **结构树样式重构**:层级连接线(::before/::after)、内联 SVG 图标、CSS 三角箭头、选中高亮+左侧边框、浮动操作栏

### v0.3.3 连线与导出 📋 计划中

- **简单连线**:可选的、只做"层与层之间"的线(仅 layered 布局),保证不破坏自动排版;模块之间的调用关系用角标标注(如 `[调用:订单中心]`),不画线
- **模块角标**:items 中以 `[调用:xx]` / `[依赖:xx]` 格式自动渲染为角标,全布局生效
- **导出 draw.io 格式**:图太复杂需要自由线时,导出去在画布工具里补(schemaVersion → 2,新增 connections 字段)

## 开源说明

- **平台**:GitHub,仓库 `archform`
- **许可**:Apache-2.0(代码和模板数据一样)
- **怎么参与**:提 issue(Bug 或模板需求),或提 PR(新增模板 / 修功能)。模板只改数据文件,没有构建步骤,门槛很低

## 几条重要的设计约定

1. **连线不能破坏排版**。连线只走层与层之间预留的通道,图里的方块位置永远不变,内容增删时线自动跟着层走
2. **连线是可选项**。默认没有线,需要才打开;旧数据完全不受影响
3. **模块之间不画线**,用角标标注关系(如 `[调用:xx]`)
4. **自由画线不在范围内**。需要复杂手绘时,用 draw.io 等画布工具;本工具可以导出 draw.io 格式,方便"结构在这里画,曲线去那边补"
5. **数据兼容**。所有文件带版本号,旧文件打开时自动升级;比工具更新的文件会给出友好提示,不会白屏或崩溃
