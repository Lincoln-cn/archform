# ArchForm 使用指南

> 项目定位、特性与快速开始见根目录 [README](../README.md);版本规划与设计边界见 [ROADMAP.md](ROADMAP.md)。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 编辑器骨架(内联样式规范 + 页面结构,双击浏览器打开即用;GitHub Pages 可直接托管) |
| `editor-core.js` | 数据与工具:状态、节点查找、模板加载、数据版本化(`migrateDiagram`) |
| `editor-render.js` | 渲染引擎:2 种板式(多层横向 / 横向流向) |
| `editor-ui.js` | 交互:结构树、属性面板、配色方案、编辑操作、导入导出、SVG/PNG 导出、缩放预览、初始化 |
| `templates.js` | 预置模板库(12 个:通用分层 + 总体/应用/数据/技术 架构四件套 + 中台/云平台/微服务/安全架构 + 3 个横向流向模板,内容为中性占位) |

> 依赖:**零运行时依赖、零网络依赖**。编辑、渲染、导出 SVG/PNG/独立 HTML 全部离线可用。

## 打开方式

双击 `index.html`,用 Chrome / Edge 打开即可(file:// 直接打开,无需服务器);或托管到任意静态站点(含 GitHub Pages)在线使用。

## 使用步骤

1. **开始**:
   - 从模板开始:工具栏「模板 ▾」按布局分组选择(横向布局 / 纵向布局),加载后替换为实际内容(预置 12 个模板:通用分层 / 系统总体架构 / 应用架构 / 数据架构 / 技术架构 / 中台架构 / 云平台架构 / 微服务架构 / 安全架构(等保 2.0) / 数据流转·横向流向 / 服务调用链路·横向流向 / 事件流·横向流向)。切换模板会**保留当前已选配色方案**并自动重绘。
   - 从零开始:点「文件 ▾ → 新建空白图」,再点「+ 新增层」逐级搭建。
2. **编辑内容**(结构树 + 属性面板):
   - 左侧**结构树**:图 → 层 → 分组 → 模块 四级。点击箭头展开/折叠;悬停节点出现 `+`(新增子项)、`↑↓`(排序)、`×`(删除);点击选中。
   - 右侧**属性面板**:随选中节点变化——图标题/副标题/板式、层名称/竖条颜色/列数/统计、分组标题、模块名称/副标题/条目列表。
   - **条目**(模块内的小标签):输入框回车即新增,点 `×` 删除;条目中 `[调用:xx]` / `[依赖:xx]` 格式自动渲染为橙色角标(全布局生效)。
   - 画布上直接点击任意模块也可选中编辑。
3. **换板式**:属性面板选中「图」,改「布局范式」即可在同一份内容上切换 **多层横向 / 横向流向**,数据不丢失。旧 卡片网格 / 中央核心 数据会在打开时自动转为 多层横向。
4. **配色**:工具栏「配色 ▾」一键套用预置风格(经典蓝/青绿/紫罗兰/暖橙/墨绿/灰蓝),或展开菜单底部自定义六档色阶并应用;配色随图保存,刷新与导出保持一致(含右侧通栏竖条)。
5. **层间连线**(仅 layered 布局):图属性中配置 `connections` 数组(指定任意层对 from/to,可选标签和线型);视图菜单切换连线开关(showConnections)。连线走层间通道,不改变模块位置。
6. **导出**(全部离线):
   - 「导出PNG」:下载整图高清 PNG(2 倍缩放,含当前配色,不含编辑界面)。
   - 「文件 ▾ → 导出SVG」:下载矢量 SVG(可无损缩放,可进一步编辑)。
   - 「文件 ▾ → 保存为HTML」:生成独立 HTML(含完整样式与当前配色、内嵌矢量图数据,可交付、可插入文档、可再次下载 PNG)。
   - 「文件 ▾ → 导出 draw.io」:导出 `.drawio` XML 文件,可导入 draw.io 补充自由曲线等编辑;作为复杂连线的逃生通道。

## 工具栏说明

- **文件 ▾**：新建空白图 / 保存到本地 / 导入JSON / 导出JSON / 导出SVG / 保存为HTML / 导出 draw.io
- **视图 ▾**：预览（Esc 退出）/ 100%缩放 / 适应宽度 / 连线开关（showConnections,仅 layered 布局）
- **配色 ▾**：预置配色方案 + 自定义六档色阶
- **模板 ▾**：按布局分组的模板菜单（横向布局 / 纵向布局），点击即加载，自动保留当前配色
- 常驻：缩放滑块、`+ 新增层`、`导出PNG`

## 布局范式（板式）

| 板式 | 结构 | 适用 |
|---|---|---|
| 多层横向 | 层(竖排 band) → 分组 → 模块卡片 → 条目 | 分层/模块类框图（默认） |
| 横向流向 | 层(列) → 分组(纵叠) → 模块(整宽行) → 条目 | 数据链路/请求流/流程通道类框图 |

## 辅助区域（所有板式通用）

- **底部图例通栏**：结构树 →「底部图例」→ `+` 新增图例项，可配置色块颜色与描述文字；导出时随图输出。
- **右侧通栏（体系说明）**：结构树 →「右侧通栏（体系说明）」→ `+` 新增体系；**体系名横排置顶**，说明条目为**竖排**窄条横向并排（与左侧层带视觉呼应、层级分明）；条目越多的体系越宽，通栏总宽随内容自动调整（最少约 3 个条目宽）；无条目时横排标题充满整块。竖条主体与边框随配色方案联动。旧数据中的 `sidebarWidth` 字段保留但不再参与布局。
- **竖条颜色**：层竖条与体系竖条提供 6 档预置色板 + 自定义取色器。

## 配色方案

- 预置 6 套：经典蓝 / 青绿 / 紫罗兰 / 暖橙 / 墨绿 / 灰蓝。套用时自动替换图中所有层带/通栏/图例颜色为方案对应色阶,并同步分组框、模块卡、条目、虚线框、面板底色、右侧通栏竖条等语义变量(五级梯度:层带→层底→分组→卡→条目)。
- 自定义：菜单底部六档取色器（从左到右为 亮/次亮/中/次深/深/最深），「应用自定义配色」保存并套用；自定义配色随图 JSON 一起保存/导出；应用时由六档色阶自动推导分组/卡片/文字语义变量。
- **非色阶颜色的处理**:图中任何不在当前方案色阶内的颜色(模板语义色、历史遗留色、导入数据的颜色),套用方案时按**RGB 最近色**映射到当前方案最接近的档位,保证整图颜色跟随方案统一变化。

### 语义 token 与五级视觉梯度

配色不仅换「主色」,还带出一套分层展示用的语义变量,保证多层/flow 下主题一致、层归属可辨：

| 层级 | 视觉 | 相关 token / 来源 |
|---|---|---|
| 层带 band | 深实心 + 白字 + 轻阴影 | 层数据色 `bandColor` |
| 层 body | 极浅 band tint(每层不同,约 7% band 色混白) | JS 内联注入;CSS 回退 `var(--layer-tint,#fff)` |
| 分组框 subdomain | 浅主题底 + 边框 + 深主题标题 | `--group-bg` / `--group-border` / `--group-ink` |
| 模块卡 card | 浅主题底 + 主题描边 + 深色字(不再实心) | `--card-bg` / `--card-border` / `--card-ink` |
| 条目 item | 白底 + 主题深字 + 细边框 | `background:#fff` + `color:var(--card-ink)` + `border:var(--group-border)` |

统计/图例次要文字使用 `--ink-muted`。导出 SVG/PNG/HTML 与画布一致(tint 走 inline,语义变量随 `ARCH_CSS` + 当前主题 vars 带出)。

自定义六档标签：亮 / 次亮 / 中 / 次深 / 深 / 最深(对应 colors[0..5]),第 3 档通常为方案主色。

## 数据管理

- **自动保存**：编辑内容实时存入浏览器 `localStorage`，刷新不丢。
- **数据版本化**：图数据带 `schemaVersion`（当前版本 2），加载时经 `migrateDiagram` 自动迁移/兜底；旧数据（无版本号）视为 v1 正常打开；版本过高时友好提示（见 [ROADMAP.md](ROADMAP.md)「数据兼容承诺」）。
- **导出 JSON**：把当前图（含配色）存为 `.json`，可换机器/换项目继续编辑。
- **导入 JSON**：打开「导入JSON」选择文件恢复。
- **预置模板**：`templates.js` 中 `window.ARCH_TEMPLATES` 对象，按同样结构增删即可扩展；模板菜单按布局（`flow`→横向布局 / `layered`→纵向布局）自动分组。

## 数据模型（JSON 结构）

```
Diagram
├─ schemaVersion                 // 数据版本（当前 2，缺省视为 1）
├─ title / subtitle / layout     // 标题、副标题、板式（layered/flow）
├─ theme                         // 配色方案（id / custom 六档色阶 / vars 主题变量）
├─ layers[]                      // 层 / 卡片 / 模块（按板式解释）
│  ├─ name / bandColor / cols / stat // 层属性
│  ├─ groups[]                   // 分组
│  │  ├─ title
│  │  └─ blocks[]                // 模块
│  │     ├─ title / sub          // 名称、副标题
│  │     ├─ items[]              // 条目（字符串，或 {text,cat,reuse} 对象）
│  │     └─ span                 // 1=正常，2=整行
├─ connections[]                 // 层间连线（可选数组，仅 layered 布局渲染；每项 {id,from,to,label?,style?}，from/to 为层 id；缺省空数组不渲染、不改变布局）
├─ showConnections               // 连线视图开关（布尔值，持久化；true 时渲染连线层）
└─ sidebar[] / legend[]          // 右侧通栏体系、底部图例
```

## 通用性说明

- 纯前端，不绑定任何项目；复制 `index.html` + 3 个 `editor-*.js` + `templates.js` 到新项目即可使用（保持同目录）。
- 模板数据与编辑器分离：换项目只需替换 `templates.js`，或通过「导入 JSON」加载项目自己的图数据。
- 样式规范固化在编辑器内（虚线面板、圆角 2px、字号层级），整体风格通过「配色 ▾」切换；如团队要改默认主题，改编辑器 `<style>` 中 `:root` 颜色变量即可全局生效。

## 已知限制

- **不提供自由画布与自由连线**：本工具定位是"结构化输入 → 自动排版"。连线策略（可选、不改变布局、仅层↔层）与逃生通道（导出 draw.io XML）见 [ROADMAP.md](ROADMAP.md)「设计边界」；需要自由绘制/自由曲线的场景请使用 draw.io 等画布工具。
- **localStorage 按浏览器与访问地址隔离**：换浏览器或换部署地址后，需通过「导入 JSON」恢复数据，或在新位置用「导出 JSON」重新保存。
- 模块名称的"6 字规范"等团队约定，暂未内置自动校验，可在模板数据生成时统一治理。
